# Entregas

Trabajos grupales entregables. Las guías TP 1–13 son individuales y no entregables, por lo que sus resoluciones permanecen en `practica/`.

| Trabajo | Fuente | Apuntes de estudio | Repositorio entregable |
|---|---|---|---|
| TPO — FarmaRed | [P19](../material/catedra/practica/tpo-farmared.pdf) y datasets P19A–P19I | [tpo-farmared](tpo-farmared/README.md) | `TPO-BD2/` ([GitHub](https://github.com/franciscocostaa/TPO-BD2)) |

La carpeta de apuntes indexa la consigna para estudiar. El repositorio entregable es un git independiente, excluido del repo de estudio en `.gitignore`. Contiene el código, los datos, las decisiones del grupo y el informe.
