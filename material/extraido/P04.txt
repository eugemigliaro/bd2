    2.​ Dada la siguiente vista:

         CREATE VIEW buenos_proveedores (prov, rub, ciudad ) AS
         SELECT id_proveedor, rubro, ciudad
         FROM PROVEEDOR
         WHERE rubro IN (‘Alimentos’, ‘Agro’, ‘Salud’, ‘Farmacia’)
         WITH CHECK OPTION;

         Crearla y probar las siguientes transacciones para analizar el comportamiento de la base:
            a.​ INSERT INTO buenos_proveedores (prov, rub, ciudad) VALUES ('10', 'Farmacia',
                'Paris');
            b.​ Volver a ejecutar el INSERT anterior modificando previamente el campo NOMBRE
                de la tabla PROVEEDOR para que permita nulos
            c.​ UPDATE buenos_proveedores SET rub = 'Educación' WHERE prov = '10';
            d.​ INSERT INTO buenos_proveedores (prov, rub, ciudad ) VALUES ('8', 'Deportes',
                'Roma');
