Ejercicios de restricciones de integridad referencial (RIR):

    1.​ Considere el siguiente esquema de una base de datos de una empresa de desarrollo de
        software, sus RIRs y las acciones referenciales definidas para el borrado y modificación:


         RIR​             Borrado Modificación

         R1​       ​         C​       R

         R2​       ​         R​       C

         R3​       ​         R​       R

         R4​       ​         N​       R


         R=RESTRICT, C=CASCADE, N=SET
         NULL




         Suponga la existencia de las siguientes tuplas en las respectivas tablas (solo se incluyen los
         atributos que se consideran relevantes para el ejercicio):
                   EMPLEADO: (A, 1,...) ; (B, 2,...) ; (A, 2,...)
                   PROYECTO: (1,...) ; (2,...) ; (3,...)
                   TRABAJA_EN: (A, 1, 1, ....); (A, 2, 2, ....)
                   AUSPICIO: (2, Arcor, A, 2)

               a.​ Considere que las tablas ya se encuentran creadas con sus correspondientes
                   PRIMARY KEY. Escriba las sentencias de alteración de tabla que incorporan las
                   RIRs definidas
               b.​ Indique el resultado de las siguientes operaciones teniendo en cuenta las RIRs y sus
                   tuplas. En caso de que la operación no se pueda realizar, determine qué regla/s
                   entra/n en conflicto y cuál es la causa. En caso de que sea aceptada, comente el
                   resultado que produciría (Nota: en cada caso considere el efecto sobre la instancia
                   original de la BD, los resultados no son acumulativos)
                          i.​ DELETE FROM PROYECTO WHERE IdProy = 3;

                          ii.​ UPDATE PROYECTO SET IdProy = 7 WHERE IdProy = 3;

                          iii.​ DELETE FROM PROYECTO WHERE IdProy = 1;

                          iv.​ DELETE FROM EMPLEADO WHERE TipoE = A AND NroE= 2;

                          v.​ UPDATE TRABAJA_EN SET IdProy = 3 WHERE IdProy =1;

                          vi.​ UPDATE PROYECTO SET IdProy = 5 WHERE IdProy =2;
