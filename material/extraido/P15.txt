                                        TP N°11 - Neo4j

Esta práctica se basa en el libro “Seven Databases in Seven Weeks (2nd Edition)” de Luc
Perkins.
Cabe aclarar que el libro tiene su antigüedad, por lo cual algunos de los métodos especificados
quedaron deprecados.

Antes de comenzar es necesario utilizar dockers/contenedores:
   ●​ Instalar Docker Desktop for Windows o for Mac o Docker Engine en Linux
   ●​ Para descargar la versión oficial de Neo4j ejecutar: docker pull neo4j
   ●​ Levantar el contenedor con: docker run --name Myneo4j -p 7474:7474 -p 7687:7687
       --env=NEO4J_AUTH=none -d neo4j
   ●​ Para apagar el contenedor ejecutar: docker stop Myneo4j
   ●​ Para iniciarla nuevamente ejecutar: docker start Myneo4j
   ●​ Para listar todos los contenedores existentes ejecutar: docker ps –a

Otra opción es instalar Neo4j en la PC que vayan a utilizar para este práctico: Linux installation -
Operations Manual

Abrir un web browser para acceder a la interfaz Web de Neo4j: http://localhost:7474/browser
   ●​ Eliminar el usuario y dejar en blanco el campo password (ya que configuramos el
       contenedor con No Authentication como Authentication type)

Para acceder a la línea de comandos dentro del contenedor: docker exec -it Myneo4j bash
