                                         TP N°12 – Redis

Esta práctica se basa en el libro “Seven Databases in Seven Weeks (2nd Edition)” de Luc
Perkins.

Antes de comenzar es necesario utilizar dockers/contenedores:
   ●​ Instalar Docker Desktop for Windows o for Mac o Docker Engine en Linux
   ●​ Para descargar la versión oficial de Redis ejecutar: docker pull redis
   ●​ Levantar el contenedor con: docker run --name Myredis -p 6379:6379 -d redis
   ●​ Para apagar el contenedor ejecutar: docker stop Myredis
   ●​ Para iniciarla nuevamente ejecutar: docker start Myredis
   ●​ Para listar todos los contenedores existentes ejecutar: docker ps –a

Otra opción es instalar la última versión disponible de Redis Open Source en la PC que vayan a
utilizar para este práctico: Downloads | Redis

Para acceder a la línea de comandos dentro del contenedor: docker exec -it Myredis bash
Luego acceder al cliente de Redis ejecutando: redis-cli
