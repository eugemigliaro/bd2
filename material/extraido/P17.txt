                                   TP N°13 – DynamoDB

Esta práctica se basa en el libro “Seven Databases in Seven Weeks (2nd Edition)” de Luc
Perkins.




Sin embargo, existe una versión local pensada para desarrolladores de aplicaciones sobre
DynamoDB, la cual vamos a usar para hacer los ejercicios.

Antes de comenzar es necesario utilizar dockers/contenedores:
   ●​ Instalar Docker Desktop for Windows o for Mac o Docker Engine en Linux
   ●​ Para descargar la versión oficial de DynamoDB local ejecutar: docker pull
       amazon/dynamodb-local
   ●​ Levantar el contenedor con: docker run --name Mydynamodb -p 8000:8000 -d
       amazon/dynamodb-local
   ●​ Para apagar el contenedor ejecutar: docker stop Mydynamodb
   ●​ Para iniciarla nuevamente ejecutar: docker start Mydynamodb
   ●​ Para listar todos los contenedores existentes ejecutar: docker ps –a

Para hacer los ejercicios es necesario instalar el cliente de línea de comando de Amazon (awscli). El
mismo lo pueden instalar dentro del contenedor o en la máquina host del mismo:
https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html

Si deciden instalar el cliente dentro del contenedor tendrán que acceder a la línea de comandos
dentro del contenedor como root (para poder instalar algunos paquetes que faltan como unzip y
less): docker exec -u 0 -it Mydynamodb bash

Luego es necesario configurar el awscli con el siguiente comando: aws configure
   ●​ AWS Access Key ID [None]: 1234
   ●​ AWS Secret Access Key [None]: 567890
   ●​ Default region name [None]: us-east-1
   ●​ Default output format [None]: json

Para listar las tablas existentes en nuestro DynamoDB es necesario ejecutar: aws dynamodb
list-tables --endpoint-url http://localhost:8000

El AWS CLI no puede usar la versión local de DynamoDB como endpoint default, es por ello que hay que
agregar el parámetro --endpoint-url con cada comando de AWS CLI.
