# Notas de clase

Las notas son evidencia personal, no material oficial. Se conservan incluso después de enriquecer la wiki.

## Captura rápida

```bash
./scripts/nueva-nota.sh "joins y subconsultas"
```

También podés copiar `PLANTILLA.md` a `notas/bandeja/AAAA-MM-DD-tema.md`. Escribí con libertad: marcá dudas, ejemplos del docente y observaciones que no estén en las diapositivas.

Al terminar, pedile al agente `procesá mis notas pendientes`. El flujo:

1. lee las notas completas;
2. las contrasta con el material oficial;
3. actualiza automáticamente la wiki con citas a ambas procedencias;
4. registra dudas o contradicciones;
5. mueve el archivo original, sin reescribir su contenido, a `procesadas/`.
