# Ejercicio MongoDB — E-commerce

- Enunciado: [P11](../../material/catedra/practica/p11-mongodb-ecommerce.pdf).
- Solución de la cátedra: [P11A](../../material/catedra/practica/recursos/p11-solucion-mongodb-ecommerce.pdf).
- Apuntes: [modelado](../../wiki/temas/16-mongodb-modelado.md) y [agregaciones](../../wiki/temas/18-mongodb-agregaciones-y-vistas.md).
- Motor: MongoDB; el enunciado propone Compass.
- Estado: pendiente de resolución individual.

El PDF incluye datos para tres clientes, tres productos y tres órdenes. Las órdenes tienen fecha, referencia al cliente y un arreglo `items` con referencia al producto y cantidad. Pide gasto por cliente, producto más vendido, ventas por categoría, top 5 con país y detalle opcional de órdenes y productos por cliente. [P11, pp. 1–2]

La solución oficial está archivada como fuente, separada de cualquier respuesta propia. Antes de usarla como referencia completa, revisar las omisiones de país y de estructura de órdenes y el empate entre productos en [dudas y conflictos](../../wiki/dudas-y-conflictos.md). [P11, p. 1; P11A, pp. 2–4]
