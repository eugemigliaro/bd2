Los ejercicios `a`–`k` trabajan selección, filtros, `DISTINCT`, orden, concatenación, fechas, nulos y agrupamiento. [P03, pp. 2–3]

Levantá el entorno con `make db-up` y escribí las respuestas en `consultas.sql`. Un agente que corrija debe ejecutar las consultas, verificar columnas/filas y explicar cualquier diferencia de dialecto.
